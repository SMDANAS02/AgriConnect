# AgriConnect Frontend

React 18 Single Page Application powered by Vite & Tailwind CSS for the AgriConnect Smart Farming platform.

## 🚀 Setup & Execution

1. Install Dependencies:
   ```bash
   npm install
   ```

2. Environment Setup:
   ```bash
   cp .env.example .env
   ```

3. Run Development Server:
   ```bash
   npm run dev
   ```

Open `http://localhost:3000` to view in browser.

## 🎨 Theme & Styling
- Tailwind CSS with customized `agri-*` green color palette (`agri-50` to `agri-900`).
- Lucide React icon suite.
- Glassmorphism & responsive agricultural UI components.
